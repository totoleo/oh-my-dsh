# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code.

## What is a changeset?

A changeset is a piece of information about changes made in a branch or PR. It contains two main pieces of information:

- Which packages the changes affect
- The type of the change (major, minor, or patch)

## How to add a changeset

```bash
pnpm changeset
```

Select the packages you changed, the bump type, and write a short summary. Commit the generated file under `.changeset/` with your PR.

## How releases work

1. PRs merge into `master` with their changeset files.
2. CI runs `pnpm version-packages` (via the release workflow) and opens a **Version Packages** PR that bumps versions and updates each package's `CHANGELOG.md`.
3. Merging that PR publishes the changed packages to npm.

See [`@changesets/cli`](https://github.com/changesets/changesets) for details.
