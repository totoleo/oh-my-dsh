# Changelog

## [2.1.0] - 2026-10-30

首个公开发布（`@totoleo/dsh-wish-mode`）。

- 四层许愿流程：**高度**是对话；**深度 / 广度 / 速度**由插件托管 goal 自动探索，每层结束必须经用户确认。
- 高度层把「做法」抬成「结果」：九个探针按缺口选，插件生成「需求回述」卡供用户逐条纠正，`confirm` 前必须 record 出 `surfaced`（这次谈出来的、原话里没有的点）。
- 探索过程与产物落盘到工作区 `wishes/<目录名>/<层>/`（目录名是 3–5 个英文单词），工具守卫把写入限制在该目录内。
- 许愿骨 **W** 图标（W = Wish）：输入框 chip 为单色剪影，插件大图标为橙 / 紫撞色。
- 16 例黑盒回归测试（`node test/harness.mjs`）。
